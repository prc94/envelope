# Envelope 0.1.0rc1

First release candidate of the single-file MCP command server. Requires CPython
3.12 or newer; the server uses only the Python standard library.

## Included

- `run`: execute commands in an available shell, with bounded output, working
  directory, environment, input and optional execution deadline.
- `output`: read, page, grep or wait for saved command output.
- `stop`: stop a background command by handle or name.
- `processes`: inspect running commands and unseen completion results.
- Long commands return a handle after the configured wait and keep running.
  Named servers and watchers support joining and restarting without starting copies.
- Bash, sh, zsh, fish, Git Bash, PowerShell 7, Windows PowerShell 5.1, cmd and
  configurable custom shells, when available on the host.
- MCP over stdio, with legacy initialization and stateless discovery support.
- Windows support tested as a standard user with AppLocker, WDAC and constrained
  PowerShell policies enforcing.

## Install

Download `envelope.pyz` and verify it against `SHA256SUMS`. No package installation
is required. Register the full path to Python and `envelope.pyz` in your MCP client;
see the accompanying `INSTALL.md` for OpenCode and Qwen Code configuration.

## Release-candidate limits

- Agent success and token-cost acceptance remains open. The latest gate attempts
  had incomplete DeepSeek coverage because of upstream rate limits; the partial
  Linux report missed the token target and Windows was inconclusive.
- OpenCode with Qwen3.8 Flash has a known task-loss issue with its stock build-agent
  prompt. A concise build prompt passed the focused pilot and full Linux slice;
  the tested workaround is included in `INSTALL.md`.
- macOS graceful stop and port ownership remain unverified; CPU sampling is not
  implemented there. Port checks can report unverified ownership when inspection
  is unavailable on other hosts.
- Slow-starting shells can be marked unavailable by the five-second discovery
  budget. Windows PowerShell 5.1's version/policy probe exceeded that budget on the
  release test VM; cmd, Git Bash and PowerShell 7 passed the artifact lifecycle
  checks there. Use `doctor` to check availability on your machine.
- Envelope runs commands with the caller's privileges. It does not provide a sandbox.

Feedback is welcome on client compatibility, shell behavior, background-process
cleanup and output retrieval. This prerelease does not close the stable-release
acceptance task.

## Artifact validation

The same `envelope.pyz` was exercised on Linux with Python 3.12.14 and on the
standard-user Windows test VM with Python 3.12.10. Checks covered discovery,
legacy and stateless tool catalogs, command execution, background commands,
saved output, stop and shutdown cleanup, using isolated Python without site
packages. See `0.1.0rc1-validation.md` in the source repository for the evidence.
