# 0.1.0rc1 validation

Validated on 2026-10-13 before tagging. The zipapp was built once and copied to the
Windows test VM; every successful artifact check reported this same SHA-256:


## Repository checks

`scripts/dev.sh all`, using the Python 3.12 floor interpreter, passed:

- Ruff lint and format checks.
- Type checks for the server and evaluation harness: zero errors or warnings.
- 566 tests in 606.67 seconds.

The release verifier was extended while those tests ran; its final lint and type
checks also passed, and the final verifier was exercised against the artifact on
both hosts. Packaging checks validated the individual file manifest and ZIP
checksum, then extracted the bundle to a fresh temporary directory and rechecked
every file against the internal manifest.

## Artifact checks

`scripts/verify_release.py` launches the artifact with `-I -S`, an empty explicit
configuration and a temporary workspace/spool. It imports no repository modules
and requires no third-party packages. It checks version, embedded license,
discovery, legacy and stateless tool catalogs, short command execution, named
background commands, process listing, output retrieval, stop and cleanup on
server stdin closure. Child process liveness is checked after stop and shutdown.

| Host | Python | Shell | Result |

| Linux | 3.12.14 | bash | Passed |
| Windows standard-user VM | 3.12.10 | cmd | Passed |
| Windows standard-user VM | 3.12.10 | git-bash | Passed |
| Windows standard-user VM | 3.12.10 | pwsh | Passed |
| Windows standard-user VM | 3.12.10 | powershell | Unavailable during discovery |

Windows PowerShell 5.1 exceeded the built-in five-second discovery budget in two
artifact smoke attempts. Direct host probes confirmed the executable works:
version-only took 2.50 seconds, while the complete version/language-mode/execution-
policy probe took 5.41 seconds and reported
`5.1.19041.7725|ConstrainedLanguage|RemoteSigned`. This host limitation is included
in the release notes; it was not hidden by raising the verifier's discovery budget
or modifying the server's probe. The Windows VM retains its documented enforcing
AppLocker/WDAC configuration.

## Acceptance status

Publishing this RC leaves the stable-release acceptance task open. The concise
OpenCode/Qwen profile passed the focused pilot (15/15 per arm) and full Linux
slice (21/21 per arm). The full evaluation attempts had incomplete DeepSeek
coverage; the partial Linux token condition was not met and both Windows
conditions were inconclusive. Those reports do not establish stable acceptance.
